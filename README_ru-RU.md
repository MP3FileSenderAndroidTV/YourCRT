# YourCRT

**YourCRT: Ютубчик, который мы заслужили в 2009-ом, сука.**

[English](README.md) | [Polski](README_pl-PL.md)

**YourCRT** — это нативный клиент YouTube, чисто для **Sony Ericsson Xperia X10 Mini (E10i/E10a)** на **стоковом Android 1.6 (Donut)**.

Никаких кастомных прошивок, никаких ядер от мамкиных хакеров — только чистый функционал для этой мелкой легенды "Robyn". Работает четко, как хедшот с дигла.

# Реконструкция 2009 (Назад в прошлое, пацаны)

Тру-поиск: Фиды настроены на „Самые просмотры“ и „Похожие“. Всё как в 2009-ом, до того как эти ебаные алгоритмы начали пихать нам всякую дичь в рекомендации.

Интерфейс без соплей: Современные „Звездочки“ пошли нахуй. Вместо них — суровые счетчики Лайков/Дизлайков. Выглядит как олдскул, а данные тянет из свежего API. Изи катка.

Только V1 Подпись: APK подписан чисто через JAR (V1). Потому что этот тупой установщик в Android 1.6 вертел на девайсе все новые подписи и выдает ошибку синтаксиса, как нуб в миду.

Render Bridge (Магия вне Хогвартса): У Доната с современным SSL отношения как у меня с экономикой — нихера не понятно. Поэтому обходим этот мусор через HTTP-мост на Рендере. Коннектимся к API v3 без лишнего гемора.

# Техническое дерьмо и Оптимизация

Свой API Ключ: Архитектура Direct-to-Google. Вбиваешь свой ключ и сидишь ровно, по правилам, без всяких банов.

Память — моё почтение: Оптимизировано под 64GB MicroSD на софте 2010 года. Я туда всунул 64 гига, Карл! Можно кэшировать превьюшки до конца жизни, места хватит.

ФПС на высоте: Принудительный поток 144p/240p (itag 17/36). Больше этот проц ARMv6 600MHz не вывезет — он просто сгорит к чертям собачьим, если попробовать запустить HD.

# Разработка и Деплой (Сделано на коленке)

Главный девайс: Xiaomi 22126RN91Y (Redmi 12C). Мой старый FIG-LX1 решил косплеить беременную бабу — батарея вздулась так, что чуть корпус не лопнул, пиздец.

Инструментарий: MT Manager (хирургия Смали без наркоза).

База: Распотрошенный и униженный код notPipe. Все скреперы (Invidious, Yt2009, S60Tube и т.д.) и загрузку видео я выкинул на помойку, чтобы билд был легким и стабильным, как калаш.
